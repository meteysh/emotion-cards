# Карточки эмоций

Веб-приложение на чистом JavaScript (без сборки и зависимостей).

Сверху или слева — лента карточек эмоций (картинка, цвет, слово). Карточки перетаскивают
в поле раскладки, меняют там порядок, возвращают обратно, сохраняют раскладку и выгружают статистику в CSV.

## Запуск

Откройте `index.html` в браузере. Надёжнее через локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Управление

| Действие | Мышь / палец | Клавиатура |
|---|---|---|
| Взять карточку | перетащить из ленты в поле раскладки (или двойной клик) | Tab к карточке, Enter |
| Поменять порядок | перетащить внутри правого поля | ← / → |
| Вернуть в ленту | перетащить в ленту или кнопка × | Delete |
| Листать ленту | колесо мыши / тачпад / полоса прокрутки; пальцем — свайп вдоль ленты | Tab |
| Переставить ленту (сверху ↔ слева) | кнопка с иконкой ленты в шапке | Tab, Enter |

На сенсорном экране перетаскивание начинается после короткого удержания пальца (~0,2 с) — обычный свайп прокручивает список.

## Офлайн-режим

Service worker (`sw.js`) при первом открытии страницы скачивает в кэш все файлы приложения —
страницу, стили, скрипты и картинки карточек (список берётся из `js/cards-data.js`).
После этого приложение открывается и полностью работает без интернета, в том числе в новой вкладке.
При первой установке показывается уведомление «Приложение сохранено и работает без интернета»,
без сети рядом с заголовком появляется метка «офлайн».

- Страница загружается «сначала из сети» (до 4 с), без сети — из кэша; поэтому обновления приходят сами.
- Стили, скрипты и картинки — «сначала из кэша».
- Версия кэша = метка `?v=` в `index.html`. **При любом изменении файлов увеличьте `?v=` у всех
  подключений в `index.html`** — у пользователей скачается новая версия, а старый кэш удалится.
  Сохранения в IndexedDB при этом не трогаются.
- Service worker работает только по `https://` или на `localhost`. При открытии `index.html`
  как файла (`file://`) приложение работает как раньше, но без офлайн-кэша.

## Устройства и положение ленты

Положение ленты карточек выбирается по положению экрана:

- **горизонтальное** (ПК, планшет или телефон «лёжа») — лента **сверху**: горизонтальная, во всю ширину,
  карточки в один ряд, высота ленты = высота карточки; листается колесом мыши, тачпадом или свайпом вбок;
- **вертикальное** (планшет или телефон «стоя») — лента **слева**: вертикальная, во всю высоту,
  в одну колонку, ширина ленты = ширина карточки; листается свайпом вверх-вниз.

Кнопка с иконкой ленты в шапке переключает «сверху ↔ слева». Выбор запоминается в браузере
(localStorage) отдельно для горизонтального и вертикального положения экрана: при повороте устройства
лента встаёт так, как пользователь выбрал для этого положения. Логика — в `js/layout.js`, он подключён
в `<head>`, чтобы раскладка не «прыгала» при загрузке.

Поле раскладки — резиновая сетка, размер карточек подстраивается под ширину экрана.
Учтены вырезы экрана (safe area), адресная строка мобильных браузеров (`100dvh`),
контекстное меню при долгом нажатии отключено.

Проверено на эмуляции ПК, Galaxy Tab S4, iPad Pro 11, Pixel 7, iPhone 13 в обеих ориентациях.

## Хранение (IndexedDB)

База `emotion-cards`:

- `cards` — карточки вместе с картинками (Blob);
- `saves` — сохранения:
  ```json
  { "id": 1, "savedAt": "2026-11-09T06:07:10.817Z", "timezoneOffsetMin": 180,
    "cards": [ { "position": 1, "id": "rage", "word": "Ярость", "color": "#E53935" } ] }
  ```
- `state` — текущая несохранённая раскладка (переживает перезагрузку страницы).

IndexedDB спокойно хранит сотни мегабайт (квота — доля свободного места на диске).
При первом сохранении приложение запрашивает `navigator.storage.persist()`, чтобы браузер не удалял данные при нехватке места.
Текущий объём и квота показаны в заголовке «История сохранений».

## CSV

Разделитель `;`, кодировка UTF-8 с BOM — файл сразу открывается в Excel с русской локалью.
Одна строка = одна карточка в одном сохранении:

```
save_id;saved_at_iso;date;time;cards_total;position;card_id;emotion;color
```

Слово всегда в одну строку — у длинных слов шрифт автоматически меньше.

### Добавление карточки

1. Положите иллюстрацию в `images/cards/<id>.jpg`. Нужна только верхняя часть карточки, без полосы со словом,
   с пропорциями 4:5 (например, 138×172). Если меняете картинку существующей карточки — дайте файлу новое имя,
   иначе у пользователей останется старая, уже сохранённая в базе.
2. Допишите объект в массив `CARDS` в `js/cards-data.js`:

   ```js
   { id: 'fear', word: 'Страх', color: '#7E57C2', labelColor: '#B39DDB', image: 'images/cards/fear.jpg' }
   ```

   - `id` — уникальный и неизменный, по нему связаны сохранения;
   - `color` — цвет верхней и нижней полос (он же уходит в CSV);
   - `labelColor` — цвет средней полосы со словом (если не задан, берётся более светлый оттенок `color`).
3. Увеличьте `?v=` у подключаемых файлов в `index.html` — браузеры и офлайн-кэш получат новую версию.

При следующем открытии новые и изменённые карточки сами попадут в IndexedDB вместе с картинками,
а удалённые из набора уберутся из базы. Сохранённая история при этом не меняется.

Если страница открыта как файл (`file://`), браузер не даёт прочитать картинку в базу. Тогда она
показывается по прямой ссылке, а сохранить её в базу приложение попробует при следующем открытии через сервер.
