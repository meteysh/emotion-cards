# Карточки эмоций

Веб-приложение на чистом JavaScript (без сборки и зависимостей).

Слева — список карточек эмоций (картинка, цвет, слово). Их можно перетащить в правое поле,
менять там порядок, возвращать обратно, сохранять раскладку и выгружать статистику в CSV.

## Запуск

Откройте `index.html` в браузере. Надёжнее через локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Управление

| Действие | Мышь / палец | Клавиатура |
|---|---|---|
| Взять карточку | перетащить в правое поле (или двойной клик) | Tab к карточке, Enter |
| Поменять порядок | перетащить внутри правого поля | ← / → |
| Вернуть в список | перетащить влево или кнопка × | Delete |

На сенсорном экране перетаскивание начинается после короткого удержания пальца (~0,2 с) — обычный свайп прокручивает список.

## Устройства

Интерфейс адаптивный и проверен на эмуляции ПК, смартфонов (Pixel 7, iPhone 13 — портрет и альбом)
и планшетов (Galaxy Tab S4, iPad Pro 11 — портрет и альбом):

- **ПК и планшет** — список и поле выбранных рядом;
- **смартфон, портрет** — список сверху, поле выбранных снизу, оба на одном экране;
- **смартфон, альбом** — панели рядом, компактная шапка;
- карточки — резиновая сетка, размер подстраивается под ширину экрана;
- учтены вырезы экрана (safe area), адресная строка мобильных браузеров (`100dvh`), контекстное меню при долгом нажатии отключено.

Взятая карточка в списке становится серой и недоступной, пока её не вернут.

Кнопки: **Сохранить** — порядок карт + дата/время в историю; **Сбросить** — всё обратно в список;
**Экспорт CSV / JSON** — выгрузка всех сохранений. Из истории раскладку можно открыть снова или удалить.

## Хранение (IndexedDB)

База `emotion-cards`:

- `cards` — карточки вместе с картинками (Blob);
- `saves` — сохранения:
  ```json
  { "id": 1, "savedAt": "2026-11-09T06:07:10.817Z", "timezoneOffsetMin": 180,
    "cards": [ { "position": 1, "id": "rage", "word": "Ярость", "color": "#E53935" } ] }
  ```
- `state` — текущая несохранённая раскладка (переживает перезагрузку страницы).

IndexedDB спокойно хранит сотни мегабайт (квота — доля свободного места на диске).
При первом сохранении приложение запрашивает `navigator.storage.persist()`, чтобы браузер не удалял данные при нехватке места.
Текущий объём и квота показаны в заголовке «История сохранений».

## CSV

Разделитель `;`, кодировка UTF-8 с BOM — файл сразу открывается в Excel с русской локалью.
Одна строка = одна карточка в одном сохранении:

```
save_id;saved_at_iso;date;time;cards_total;position;card_id;emotion;color
```

## Добавление карточек

Допишите объект в массив `CARDS` в `js/cards-data.js`:

```js
{ id: 'awe', word: 'Трепет', color: '#C5CAE9', image: 'images/awe.png' }
```

`id` должен быть уникальным и не меняться — по нему связаны сохранения.
Без `image` рисуется встроенная SVG-иллюстрация по параметрам `face`.
При следующем открытии новые и изменённые карточки автоматически попадут в базу.
